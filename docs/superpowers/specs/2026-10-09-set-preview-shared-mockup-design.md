# Превью сета: общий макет редактора + стена-плакат

Версия-цель: 4.10.0. Автор: контроллер + пользователь по замечаниям к 4.9.3.

## Мотивация

Пользователь проверил 4.9.3 в игре. Одобрено (без изменений): 30/70 колонок, серые
«заблокированные» клетки, заполненная клетка — только иконка с именем в тултипе,
стенка инвентаря 8×8. Замечания:

1. **Квадраты мелкие.** Компактные квадраты 58×48 в превью не заполняют площадь
   панели; во вкладке «Экипировка» слоты растянуты на всю колонку и выглядят
   «отлично подогнанными». Предложено: взять макет редактора за основу и
   переиспользовать его во всех трёх местах (вкладка, превью Sets, страница Done);
   колонку экипировки чуть расширить.
2. **Стена в пустом блоке.** Панель «Инвентарь» имеет `SIZE_EXPAND_FILL` + ratio 0.7
   — карточка растягивается на весь остаток, жёсткая стена 405×405 плавает внутри с
   полями и «теряет шарм». Решение: панель сжимается к стене (SHRINK) — стена
   становится аккуратным постером, освобождённая ширина уходит экипировке.

Пользователь выбрал **Вариант А** (один макет + стена-плакат).

## Изменения (VTKUI.gd)

### 1. `_make_equip_cell` — одна ветка, макет редактора
- Сигнатура: `(slot: String, min_h: int, desc := {}, interactive := true)`
  (параметр `fixed := false` удаляется).
- Клетка всегда `size_flags_horizontal = SIZE_EXPAND_FILL`, растягивается на
  широну колонки — как в редакторе.
- Компактная `fixed`-ветка (CenterContainer'ы + SHRINK-иконка 46×32/36×22)
  удаляется целиком. Остаётся единый макет: CenterContainer по всей клетке,
  заполненная — иконка `Picker.item_art` c `maxi(16, min_h-16)` по центру, пустая —
  подпись слота; точка занятости в углу; ✕ при `interactive and occupied`.
- Серые «заблокированные» клетки (`not interactive and src.is_empty()`) остаются
  как есть — до ветвления.

### 2. `_make_body_zone` — без `square`
- Сигнатура: `(slots: Array, eq := {}, interactive := true)` (параметр
  `square := false` удаляется).
- Зона всегда `size_flags_horizontal = SIZE_EXPAND_FILL`, высота
  `4*EQ_CELL_H + 3*EQ_GAP` запечена (не меняется).

### 3. `_make_equip_preview` — тот же макет, что `_refresh_slots`
- `_make_body_zone(body, eq, false)` — квадратность снята.
- Мелкая сетка: `custom_minimum_size = Vector2(2*EQ_SMALL_H+EQ_GAP, 0)` и
  `SIZE_SHRINK_BEGIN` убираются; сетка `SIZE_EXPAND_FILL` и клетки
  `_make_equip_cell(slot, EQ_SMALL_H, eq.get(slot), false)` — как в редакторе.
- `size_flags_stretch_ratio = 0.3` у панели удаляется (единственный сосед по ряду
  больше не растягивается).

### 4. `_make_inventory_panel` — стена-плакат
- `size_flags_horizontal = SIZE_SHRINK_BEGIN`, `size_flags_vertical =
  SIZE_SHRINK_CENTER`: панель сжимается к содержимому (заголовок + стена
  405×405) и центрируется по высоте рядом с высокой колонкой экипировки.
- `SIZE_EXPAND_FILL` и `stretch_ratio = 0.7` удаляются.
- `custom_minimum_size` (417 × 0) остаётся — это и есть ширина стены с полями.

### 5. ESC закрывает панель
- В `_input` (после блока захвата клавиши, до `_is_toggle_event`):
  если нажат `KEY_ESCAPE`/physical, то при открытой панели — `_set_panel_open(false)`,
  иначе ничего; к активности загрузки сетов по QK не ведёт. Открыть через ESC нельзя.

## Раскладка после изменения

- Вкладка «Экипировка»: без изменений (уже макет-основа).
- Превью Sets (правая колонка) и страница Done: экипировка — тот же макет, что
  вкладка (клетки растянуты), рядом постер-стена 405×405, освобождённая ширина —
  экипировке.
- Серые клетки не показываются в редакторе (`interactive=true`), только в превью.

- Тултип MCM-ключа «Toggle UI» не меняется.
