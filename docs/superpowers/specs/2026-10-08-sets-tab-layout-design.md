# Вкладка «Сеты» — компоновка H3

Статус: **утверждено пользователем 2026-10-08**.
Мокапы: `.docs/sets-mockups/` (вход — `index.html`; ключевые кадры: `h3-a-focus.html`, `h3-gear-v2.html`, `h3-gchips.html`).

## Проблема

1. Редактор открывается под общим списком сетов в одном `ScrollContainer` — до выборщика надо доскроллить.
2. Чипы снаряжения (`.gchips`) вертикальные: чем больше выбрано, тем ниже каталог — та же болезнь, что была у вкладки «Экипировка».
3. Панель обвесов — блоком под каталогом (`_gear_att_box` VTKUI.gd:804, `_equip_att_box` VTKUI.gd:751): открываясь, сжимает сетку.
4. Горизонтальная скролл-лента чипов отклонена: скролл и обрезанные карточки — визуальный проигрыш.

## Решение (одобренные секции)

### 1. Просмотр
Рейл сетов 236px слева: карточки сетов (имя, счётчик `?`, мета) + «+ Создать сет» пунктирной карточкой-формой. Активный сет — золотая рамка. Справа — превью выбранного сета.

### 2. Шаг «Экипировка»
Рейл остаётся. Чипы слотов — горизонтальной панелью фиксированной высоты. Каталог 5 колонок, в фокус-режиме 7.

### 3. Шаг «Снаряжение»
- **Категории — левым блоком** (вертикальный список со счётчиками, как в игре сейчас), ширина как `SIDE_WIDTH`. Рейла сетов на этом шаге нет.
- **Выбор живёт на карточках каталога (G2)**: золотая рамка, бейдж `×N`, контролы на карточке: `− N +`, `⚡`, `✕`; у предметов с панелью — кнопка «Обвесы». Отдельного списка чипов сверху нет: сетка начинается с первой строки, высота фиксирована всегда.
- **⚡** — спавн этого предмета (текущее количество) в живой инвентарь. Черновик не закрывает, запись в `VTKsets.json` не создаёт.
- Фильтр **«Только выбранные»** — пунктирной строкой в конце списка категорий, со счётчиком.
- **Обвесы — оверлеем поверх каталога (G2+)**: клик «Обвесы» на карточке открывает панель тем же оверлеем (скрим, клик вне — закрыть). У магазина тот же оверлей показывает «Патроны: Полная / Пустая». На шаге «Экипировка» — общий оверлей, `_rebuild_att_panel` переиспользуется без изменений, меняется только контейнер.
- Поиск — над каталогом, как сейчас (отдельный `LineEdit`, `text_changed`).

### 4. Шаг «Готово»
Имя, сводка в две колонки (`#cccccc` / `#a89a80`), действия: **[Сохранить сет]** (первичная, золото) **[Очистить] [Отмена]**. Кнопки спавна нет — спавн только по `⚡` на карточке.

### 5. Фокус-режим ⛶
Единое правило на всех шагах: кнопка «⛶ На весь экран» в шапке прячет левый блок страницы — шаги 1/3 — рейл сетов, шаг 2 — категории. В шапке появляется кнопка возврата: «Показать сеты» / «Показать категории». Каталог шага 2 в фокусе — 7 колонок. Состояние — на сессию, общее для всех шагов (не персистить в конфиг).

### 6. Крайности и локализация
- Пустой сет: заметка «Нет предметов» (существующая).
- Сброс поиска восстанавливает полный каталог; счётчики категорий — как сейчас, без изменения поведения.
- Все новые строки — английский ключ + запись в `VTKLoc.gd` RU в том же проходе; имена предметов, типы и категории из `Database` не переводятся.
- Формат `VTKsets.json` и ключи MCM не меняются — релиз с обратной совместимостью (minor).

## Отклонено

- Горизонтальная скролл-лента чипов (визуальный проигрыш).
- G1 (чипы в левой колонке над категориями) — делит колонку с категориями.
- G3 (строка-резюме + оверлей выбора как основной способ) — оверлей остался, но только для обвесов.
- Кнопка «⚡ В инвентарь без сохранения» на шаге 3 (весь сет) — спавн только поштучно на карточках.
- Вариант «категории горизонтальной панелью в правом блоке» (v2, вариант 1).
