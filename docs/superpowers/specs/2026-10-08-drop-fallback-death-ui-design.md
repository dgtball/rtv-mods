# Убрать фолбек-панель смерти из VTKHooks (v4.8.3)

Дата: 2026-10-08
Статус: утверждён в диалоге (вариант B), версия 4.8.3

## Контекст

Экран смерти в ironman: ванильная сцена Death монтируется асинхронно, и её
кнопка «Load Game» (в permadeath — серая) находится не сразу. `VTKHooks.gd`
переиспользует эту кнопку: `_repurpose_load_button` делает из неё «Restart»,
вешающий `_on_restart_pressed` (восстановление vitals, difficulty=3, вайп
сохранений, LoadScene).

Если кнопка не находилась за 20 секунд (`DEATH_FIND_TIMEOUT_MS`), мод рисовал
собственную панель `_build_fallback_panel` (Restart / Main Menu / Quit) поверх
Death. Сейчас ванильный сценарий надёжен, и старый UI больше не нужен.

## Решение

Фолбек-панель удаляется. После 20 секунд ожидания мод пишет одно
предупреждение и прекращает вмешиваться: экран остаётся ванильным как есть.
Причины пропажи кнопки будем искать по диагностической распечатке дерева.

## Изменения в `loadouts/mods/VTK/VTKHooks.gd`

Удаляется полностью:

- `_build_fallback_panel` (560–600)
- `_on_menu_pressed` (692–702) — только фолбек
- `_on_quit_pressed` (704–706) — только фолбек
- состояние `_death_restart_btn` (18) и все его проверки/очистки
  (435–437, 446–447, 634–636)
- таймаут-ветка с построением панели (470–475) и комментарии про фолбек (24–27, 34–36)

Меняется поведение:

- `DEATH_FIND_TIMEOUT_MS := 20000` и `_death_find_since` остаются —
  окно ожидания и подпись «@Nms» в дампе.
- По истечении окна вместо `_build_fallback_panel`: одно предупреждение
  «[VTK] No 'Load Game' button after Nms; leaving vanilla death screen»,
  флаг `_death_gave_up = true`, дальнейшее сканирование не ведётся.
- Флаг `_death_gave_up` сбрасывается в cleanup-ветке `_handle_death_screen`
  (смерть снята / экран ушёл), так что следующий забег сканирует заново.
- `_dump_death_tree` остаётся (диагностика), активен только в окне ожидания.

Остаётся без изменений: `_repurpose_load_button`, `_restore_load_button`,
`_find_load_button`, `_on_restart_pressed`, `_wipe_saves_for_restart`,
IRONMAN-vitals, difficulty=3.

## Стенд

В `layout_check.py` в список `GONE` добавляются символы, которых больше не
должно быть в коде: `_build_fallback_panel`, `_on_menu_pressed`,
`_on_quit_pressed`. `test_hooks.gd` не меняется — фолбек-путь ничем не
тестировался, рестарт-тест покрывает `_on_restart_pressed` напрямую.

## Версия и релиз

Текущая незакоммиченная работа идёт на 4.8.2 (killfeed-взрывы, rig-имя оружия,
agent-root). Удаление фолбека входит в этот же релиз, версия поднимается до
**4.8.3**: `loadouts/mod.txt`, `loadouts/mods/VTK/version.txt`, шапка
`README.md`. Затем: стенды (.check / layout_check), `pack.ps1`, копия
`Loadouts.vmz` в папку модов игры, релиз в Git, коммит.

## Риски и нерешённое

- Если ванильная кнопка пропадёт в будущем апдейте игры — рестарт из death
  screen без UI (ironman-игрок застрянет на серой Load Game; вайп-восстановление
  недоступно). Это принимаем осознанно: диагностика осталась, фикс сделаем по
  распечатке дерева.
