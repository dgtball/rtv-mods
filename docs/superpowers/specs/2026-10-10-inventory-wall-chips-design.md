# Стена инвентаря: чипы 1×1 без рамки, сетка 8×8 — дизайн

Статус: **предложено, ждёт ревью пользователя**.

## Проблема

Правая панель «Инвентарь» в превью сета (`_make_inventory_panel`,
`_build_set_preview`) сейчас:

- **Тянется по ширине** (`SIZE_EXPAND_FILL` на стене, `VTKUI.gd:1815`) —
  клетки становятся шире, чем выше, и поле выглядит «прямоугольным».
- **У каждого предмета своя рамка**: чип одет в стиль
  `VTKSurface.surface("normal")` (`VTKUI.gd:1766`) — отдельная обводка на
  клетке.
- **Предметы в реальном размере слота**: бутылка 1×2, банка 1×1, винтовка 2×3 —
  большие вещи захватывают четверть стены и оставляют дыры.

Пользователь хочет: все предметы — квадратные чипы 1×1, без рамки (голая сетка
+ иконка), и всегда квадратное поле 8×8.

## Решение

Клетка инвентаря — **70px**, зазор 3px → канва **8·70 + 7·3 = 581×581**
(квадрат, 8×8 при min 8 рядов). Каждый предмет — ровно одна клетка: тёмный
фон + иконка по центру + счётчик «×N» внизу справа. Рамка чипа не рисуется.
Блок «экипировка → инвентарь» прижат к левому краю превью, остаток ширины —
справа (пользователь выбрал «пусто справа»).

### Раскладка

- `_make_inventory_wall(gear)` — укладка по индексу: предмет `i` сидит в клетке
  `col = i % 8`, `row = i / 8` (все 1×1). Рядов: `rows = maxi(INVEN_ROWS,
  ceili(gear.size() / 8.0))` — поле квадратное 8×8, если стеков ≤ 64, и растёт
  по высоте дальше (клетки остаются квадратными). Сетку фона из `rows*8`
  тёмных клеток (`#14110c`, скругление 3) сохраняем.
- Стена: фиксированный `custom_minimum_size = (581, rows*70 + (rows-1)*3)` и
  `size_flags_horizontal = SIZE_SHRINK_BEGIN` (не тянется; пустота справа).
- `_wall_item(desc)` — больше не `Panel` со стилем поверхности: возвращает
  `Control` размером 1×1 (70×70) с `TextureRect` (`Picker.item_art`,
  `STRETCH_KEEP_ASPECT_CENTERED`, до ~70·0.78 ≈ 54px иконка) и бейджем «×N»
  (`Draft.shown_count`), как сейчас. Тултип и `mouse_filter = STOP` на чипе
  сохраняются (наведение без рамки — мягкая подсветка контуром).
- `_make_inventory_panel` — `size_flags_horizontal = SIZE_SHRINK_BEGIN`:
  панель не претендует на остаток ширины строки. Шапка «Инвентарь · N items ·
  grid 8 columns» без изменений.

### Что убирается

- `_gear_cell_size(desc)` (`VTKUI.gd:1743–1753`) — после перехода на 1×1
  используется только стеной и становится мёртвой.
- Укладка с реальными размерами в `_make_inventory_wall` (`col`/`row_h`,
  `rows := maxi(8, row + row_h)`, `VTKUI.gd:1796–1811`).
- Рамка чипа: `box.add_theme_stylebox_override("panel",
  VTKSurface.surface("normal"))` (`VTKUI.gd:1766`).

### Что остаётся

- `INVEN_COLS := 8`, `INVEN_GAP := 3`; константы переезжают в `INVEN_CELL :=
  70` и `INVEN_ROWS := 8` (`VTKUI.gd:1033–1035`).
- `_make_inventory_panel`, `_build_set_preview`, шапка с мета-строкой.
- Полностью изменения парсинга/данных не затрагивают: `gear` — тот же массив
  дескрипторов.

## Локализация

Новых ключей нет: используются `Inventory`, ` items · `, `grid 8 columns`.
Мета-строка «grid 8 columns» остаётся корректной (колонок по-прежнему 8).

## Стенды

`layout_check.py` пополняется вместе с задачей:

- `PRESENT`: заменить `"INVEN_CELL := 55"` на `"INVEN_CELL := 70"`, добавить
  `"INVEN_ROWS"`.
- `GONE`: `VTKSurface.surface("normal"))` (точная строка рамки чипа,
  уникальна в файле), `row_h := 1`, `_gear_cell_size` — маркеры возврата рамки
  и реальных размеров.
- `FUNCS`:
  - `("_make_inventory_wall", ["INVEN_ROWS", "Control.SIZE_SHRINK_BEGIN"],
    "стена: всегда 8+ рядов, квадратная и не тянется")`;
  - `("_wall_item", ["Picker.item_art"], "чип рисует иконку")`.

`keycheck.py`: новых/удаляемых ключей нет — прогнать для контроля.

## Проверка

- `py .check\layout_check.py` — GONE/PRESENT/FUNCS зелёные.
- `powershell -NoProfile -ExecutionPolicy Bypass -File .check\check.ps1` —
  парсинг всех `.gd` и headless-тесты.
- `keycheck.py`, `encoding_check.py` — зелёные.
- Ручная проверка в игре: в превью сета и на странице Done поле инвентаря —
  квадрат 581×581, ровные клетки 70px; предметы — чипы без рамок, иконка +
  «×N»; тултип на чипе; пустота справа от блока; при 64+ стеках поле растёт
  по высоте, при ≤64 остаётся 8×8.
- Версия в `loadouts/mod.txt` — **4.12.1** (пользователь указал при переходе к
  реализации): редизайн превью инвентаря.

## Отклонено

- **Клетка 48px** (канва 405²) — иконки мелкие; отклонена в пользу 70.
- **Клетка 56px** (канва 469²) — компромисс, не взят.
- **Авто-клетка под ширину окна** — «сколько влезет с квадратными клетками»:
  в широком окне поле вылезает по высоте, масштаб плавает; отклонено.
- **Центрирование блока** — пустота и слева (у рейла), и справа; отклонено в
  пользу «пусто справа».
- **Сохранение реальных размеров слотов** при квадратных клетках — против
  запроса пользователя (чипы 1×1).

## Риски (приняты пользователем)

- Блок 375 + 8 + 593 = **976px**: на окнах уже ~1210px — горизонтальное
  обрезание. Пользователь осознанно принял риск («1024×768 практически не
  осталось»).
- Высота поля 581px + шапка на странице Done с именем и кнопками — небольшой
  вертикальный скролл.

## Вне области

- Экипировка (левая панель превью и шаги 1) не меняется — там реальный
  размер важен (слоты), остаётся как есть.
- Редактор сета и шаги 1–2 не затрагиваются.
