# Set Preview: 30/70, квадратные слоты, серые неиспользуемые, фикс 8×8 стена

Дата: 2026-10-09. Версия релиза: **4.9.3** (patch — визуальные правки превью).

Контекст: после проверки 4.9.2 в игре принято решение поправить превью сета. Все четыре правки — только превью (правая колонка вкладки «Сеты» и шаг 3 «Готово»), редактор экипировки не меняется. Общие функции у обоих мест: `_make_equip_preview` / `_build_set_preview` / `_make_inventory_wall` / `_make_inventory_panel`.

## 1. Колонка экипировки 30/70

- `_make_equip_preview`: `panel.size_flags_stretch_ratio = 0.3`.
- `_make_inventory_panel`: `panel.size_flags_stretch_ratio = 0.7`.
- Обе панели оставляют `SIZE_EXPAND_FILL` по горизонтали.
- Минимум ширины панели экипировки уменьшается с `318` до содержательного минимума: `Vector2(132, 0)`.
  (Расчёт: зона тела 2×58 + 4 = 120, мелкие 2×48 + 4 = 100, паддинги: 6+6 сверху/снизу каждой панели. 132 покрывает 120 + рамки.)
- Минимум панели инвентаря не меняется (8×48 + 7×3 + 12 = 417).

## 2. Неиспользуемые слоты — серые «заблокированные» клетки

В превью (`interactive=false`) слот без предмета (`desc.is_empty()`) получает disabled-стиль:

- заливка `Color("#1e1a15")`,
- рамка `Color("#4a443a")`,
- подпись слота — бледная `#5f5347` (как сейчас для пустых),
- точка занятости — не золотая (`#2a1f14`), как сейчас.

Реализация: ветка «empty» стиля внутри `_make_equip_cell`, активная только при `not interactive`. Для `interactive=true` (редактор) стиль пустой клетки не меняется.

## 3. Слоты — квадраты

- `_make_equip_cell` получает флаг `fixed := false`: при `fixed=true` `custom_minimum_size = Vector2(min_h, min_h)` и `size_flags_horizontal = SIZE_SHRINK_BEGIN` вместо растяжения.
  Внутренняя вёрстка `fixed`-клетки — компактная, по макету: заполненная показывает иконку по центру (размер иконки ≈ `min_h-12`×`min_h-26`, флаги `SIZE_SHRINK_CENTER`, подпись слота не показывается, имя — в тултипе), пустая — подпись слота по центру; запятая занятости — золотая точка в правом верхнем углу. Текущую раскладку `fixed=false` (CenterContainer: иконка по центру либо подпись, точка в углу, ✕ при `interactive=true`) квадраты 58×58 не вмещают, поэтому она остаётся только у `fixed=false` — редактор инвариантен.
- `_make_body_zone` получает флаг `square := false`:
  - при `square=true` `custom_minimum_size = Vector2(2 * EQ_CELL_H + EQ_GAP, 4 * EQ_CELL_H + 3 * EQ_GAP)` = `(120, 244)`, горизонтальный expand снимается, клетки создаются с `fixed=true`;
  - редактор (`square=false`) — как сейчас.
- Сетка мелких в `_make_equip_preview`: `sgrid` без горизонтального expand, клетки `fixed=true` (48×48). Минимальная ширина сетки 100.
- Клетки оружия остаются широкими строками высотой `EQ_WEAP_H` — не квадраты (соответствует макету `preview-v4-silhouette-wall.html`).
- Силуэт `BodySilhouette` не меняется: части центрированы якорем 0.5 по X и привязаны к рядам высотой 58px, поэтому сужение зоны тела до 120px не ломает геометрию (голова 178→, торс, ноги вписываются в те же ряды).

## 4. Стена инвентаря — фиксированная сетка 8×8

`_make_inventory_wall`:

- Всегда рисует канву `8×48 + 7×3 = 405` на `405` px: `custom_minimum_size = Vector2(405, 405)`.
- Фон — 64 серые «пустые» клетки в расцветке макета `.gcell`: заливка `#14110c`, скругление 3, рамки нет (видимая сетка даётся зазорами 3px), `mouse_filter = MOUSE_FILTER_IGNORE`. Пустые клетки пункта 2 (слоты экипировки) — заливка `#1e1a15` и рамка `#4a443a`, чтобы отличать слоты от стены.
- Предметы кладутся поверх прежней логикой расстановки (`_wall_item`, позиции `col × (INVEN_CELL + INVEN_GAP)`), корточка `clip_contents = true`.
- Высота больше не считается от содержимого; контент дальше 8 рядов обрезается (по решению пользователя «8×8 более чем достаточно», переполнение не обрабатывается).
