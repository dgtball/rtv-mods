# Сетка экипировки с силуэтом (вариант S1) — дизайн

Статус: **утверждено пользователем** (мокап `.docs/sets-mockups/s1-square-icons.html`).

## Проблема

Шаг 1 «Экипировка» держит левую колонку плоским списком из 20 строк
(`_side_slots_box` + `_make_slot_row`). Список не даёт понять, куда предмет
надевается: Шапка и Каска, Торс и Разгрузка, Штаны и Рюкзак выглядят как
равноценные строки, хотя это разные зоны тела. Тратится 232 px ширины на
текстовые строки, а иконок в слотах нет вовсе.

## Решение

Левая колонка шага 1 заменяется сеткой экипировки (вариант S1 мокапа):

```
┌ оружие (всю ширину) ───────────┐
│ [icon] Основное           ●  ✕ │
│ [icon] Дополнительное     ●  ✕ │
├ силуэт тела, 2×4 ──────────────┤
│ Шапка        │ Каска           │   ← клетки прозрачные,
│ Торс         │ Разгрузка       │     под ними силуэт
│ Штаны        │ Рюкзак          │
│ Обувь        │ Подсумок        │
├ мелкие слоты, 2×5 ─────────────┤
│ Перчатки │ Нож                 │
│ Фонарик  │ Часы                │
│ Карта    │ ПНВ                 │
│ Граната1 │ Граната2            │
│ Плеер    │ Спички              │
└────────────────────────────────┘
```

Правая колонка страницы (шапка цели, поиск, полки каталога) не меняется.

## Правила раскладки

Раскладка — презентация, а не данные, но живёт в `VTKPicker.gd` (чистая логика,
headless-тесты), как `SLOT_ORDER`:

- `equip_layout(present)` возвращает `{"weapons": [...], "body": [...], "small": [...]}`
  с уже отфильтрованными слотами: показываем только те, что есть в каталоге
  (`Picker.all_slots`). После апдейта игры лишних пустых клеток не появляется.
- Оружие: `Primary`, `Secondary` — стопкой во всю ширину.
- Тело (порядок заполнения `GridContainer` 2 колонки, слева вниз → справа вниз):
  `Head, Helmet, Torso, Rig, Legs, Backpack, Feet, Belt`.
- Мелкие (2×5): `Hands, Knife, Light, Time, Map, NVG, Grenade_1, Grenade_2,
  Player, Matches`.

## Правила клетки

- Занятая клетка показывает иконку предмета (`_item_icon` + `Picker.item_art`).
- Пустая или без иконки — имя слота (`Loc.txt(slot)`), тусклое у пустой.
- Точка в правом верхнем углу: золотая у занятой, тёмная у пустой.
- Активная цель — золотая рамка клетки.
- Занятая клетка несёт крестик в левом верхнем углу (`_remove_slot`); без него
  снятие предмета стало бы недоступным (в мокапе крестик условен).
- Заливка клеток прозрачная — силуэт тела обязан просвечивать. Рамки: пустая
  `#2a1f14`, занятая `#3a2e20`, ховер `#c9823a`, цель — золото.
- Клик — прежний `_on_slot_row_input`: выбор цели; повторный клик по занятой
  цели открывает панель обвесов. Повествование не меняется.

## Силуэт

Внутренний класс `BodySilhouette extends Control` рисует голову, торс и ноги
`Panel`'ами со `StyleBoxFlat` (заливка `#1a1510`, рамка `#2a1f14`, скругление),
центрируя их якорем 0.5 по X — силуэт остаётся по центру при любой ширине
колонки. Прозрачность 0.6. Геометрия согласована с рядами сетки: голова — ряд
Шапка/Каска, торс — ряды Торс…Штаны, ноги — ряд Обувь/Подсумок.

## Размеры

| Что | Значение |
|---|---|
| Высота клетки тела | 58 px |
| Высота клетки оружия / мелкой | 48 px |
| Зазор сетки | 4 px |
| Высота зоны силуэта | 4×58 + 3×4 = 244 px |
| Ширина колонки | `SIDE_WIDTH` = 232 px (не трогаем: делится со шагом 2) |

Клетки тянутся по ширине (`SIZE_EXPAND_FILL`), 2 колонки делят ширину панели
пополам, поэтому фиксированная ширина клетки не нужна.

## Локализация

Новых строк нет: имена слотов уже в `VTKLoc.gd`, заголовок страницы берёт
существующий ключ `Equipment`. `keycheck.py` не меняется.

## Локализация точек изменений

| Что | Где |
|---|---|
| Плейсхолдер колонки `_side_slots_box` → `_equip_grid_box` | var (48), null-сброс (~799), `_build_page_equipment` (1105) |
| Сетка: оружие, силуэт, мелкие слоты | `_refresh_slots` (1624) |
| Клетки и стиль | новые `_make_equip_cell`, `_make_weapon_cell`, `_make_body_zone`, `_equip_cell_style`, класс `BodySilhouette` |
| Раскладка | `VTKPicker.equip_layout` + `EQUIP_WEAPONS/EQUIP_BODY/EQUIP_SMALL` |
| Строка слота удаляется | `_make_slot_row` (1650) |

## Отклонено

- Изменение правой колонки (полки каталога остаются как есть).
- Правка `SIDE_WIDTH` (разъехались бы шаги 1 и 2).
- Хардкод списка слотов в UI (нужна отфильтрованная раскладка из Picker).
