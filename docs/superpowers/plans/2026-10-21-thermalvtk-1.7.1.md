# ThermalVTK 1.7.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the body fill and the nomad marker onto the key→substitute colour contract, fix the front-face rim, remove "See through walls", fix the F6 toast, and turn "Outline style" into a fill preset.

**Architecture:** The NVG overlay reads the screen and swaps any pixel near a "key" colour for a chosen display colour; non-key pixels go through the false-colour thermal palette. 1.7.1 adds state-encoded fill keys and a nomad key so the fill and marker are detected (not palette-recoloured), moves fill density into the overlay (a `fillOpacity` uniform), and deletes the through-walls shader variant.

**Tech Stack:** Godot 4.6.3, GDScript, GDShader. Headless test harness under `.check/`.

static func _with_cull(code: String, front_faces: bool) -> String:

static func ring(front_faces: bool) -> Shader:

		return _ring_cache[key]
	var variant := Shader.new()
	variant.code = _with_cull(RING_SRC.code, front_faces)
	_ring_cache[key] = variant
