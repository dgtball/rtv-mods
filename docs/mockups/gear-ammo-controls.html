Патроны и обоймы. Макет для выбора. Клетка — реального размера: 128 px.

Данные игры (проверено headless):
· Патроны: amount = число патронов. Стак (defaultAmount) по калибру: 12x70 = 10 · 7.62x54R / 9x39 = 20 · 5.45 / 5.56 / 7.62x39 = 30 · .45 / 9x18 / 9x19 = 50. Полный = maxAmount = 300.
· Обоймы: в сете count = число обойм (этим уже рулят «−/+»), а Full magazine — тумблер заполнения каждой (патронов = вместимость).
· Сейчас шаг «−/+» всюду = 1; добавление кликом из каталога для патронов тоже = 1.

3. Ещё три идеи управления (от меня)

№1 — Колесо мыши по клетке

Наведение + скролл меняет количество, не надо целиться в «−/+». По умолчанию — шаг-стак, с Shift — на 1.

scroll 30 → 60 → 90 … 300

№2 — Клик по числу = ввод

Клик по счётчику превращает его в поле ввода: набрать точное число. Решает некратность стаку (например, 45 патронов).

45█
Enter — применить

№3 — Удержание «−/+» с ускорением

Короткое нажатие — 1, удержание — повтор и разгон до стака. Без новых кнопок, привычно как в спиннерах.

+
тап = 1 · удержание = быстро

Что решить

1. Патроны: общий шаг на **стак** (V1) или пресеты (V2) или двухъярусный (V3)?
2. Шаг-стак = сколько? Значение калибра (10/20/30/50) или фикс, напр. 30?
3. «Full» у патронов — только выставить 300, или ещё и тумблер «Empty»?
4. Обоймы: M1 (Full снизу) достаточно, или M2?
5. Брать ли какую-то из идей №1–3 в этот же заход?
