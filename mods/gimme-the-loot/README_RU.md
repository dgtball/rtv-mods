# **Gimme the Loot**

**Версия:** 1.2.2  
**Идентификатор:** `gimme-the-loot`  
**Автор:** CaptiveAI

**Gimme the Loot** добавляет в *Road to Vostok* на каждый предмет собственный **rarity tier**, который живёт на самом предмете (сохраняется, переезжает с карты на карту), плюс пассивные аффиксы, реально влияющие на геймплей (не просто тултипы).

## Что делает

- **Common** — синяя рамка, 1–2 аффикса  
- **Rare** — фиолетовая рамка, 2–3 аффикса  
- **Legendary** — золотая рамка, 3–5 аффиксов  

Предметы из контейнеров, на трупах и лежащие на земле получают тиры и пассивы; military / elite контейнеры сдвигают шансы вверх.

## Установка

1. Скопируйте `GimmeTheLoot.vmz` в папку `mods` игры.
2. Mod Configuration Menu не нужен, но опционален.

## Что меняется в игре

**Одежда (на персонаже)**
- Carry capacity
- Insulation
- Sprint speed
- Более медленный drain stamina/hunger/thirst/sanity
- Regen, в т.ч. Low HP
- max_hp
- Frost Resistant (Legendary одежда: иммунитет к обморожению, пока надето)
- Detection range ИИ (Noise)
- Perks-like Extra Loot (шанс получить лишний лут)
- Protection (helmet/armor plate)
- Unbreakable (шлем и разгрузка: прочность не падает ниже найденной, ремонт работает)

**Гаджеты**
- Extra Loot и Sanity Drain (часы и карта)
- Battery Save: фонарик, ПНВ и кассетный плеер садятся на 5–10% / 20–50% / 70–90% медленнее по тиру

**Оружие**
- Damage
- Recoil
- Low-HP damage
- Wear Resistance (шанс не потерять прочность при выстреле: 10–20% / 20–35% / 35–60% по тиру)
- Ammo Save (шанс не потратить патрон)
- Never Jam (с Rare: исправное оружие не клинит, при 0% прочности клин остаётся)
- Unbreakable (только Legendary: прочность не падает ниже найденной)

## Настройки MCM

### 01. Display
- Подсветка ячеек
- Блок аффиксов в тултипе
- Палитра Rare/Legendary

### 02. Balance
- Множитель частоты редких тиров 0.5–2.0×
- Контекстный hint для контейнеров

### 03. Debug (только dev‑режим / файл `user://rtl_dev`)
- Debug mode
- Force tier
- Re-roll hovered item
- Log rolls

## Совместимость

⚠ **Не рекомендуется использовать вместе с Evolve или ItemClarity.**  
Моды перехватывают одни seam'ы (character-clamp, sensor, UpdateStats, PlateCheck/HelmetCheck); резолв через `priority=-1` может отобрать замену у другого мода — получатся нулевые/no-op passive.

## Примечания

- Редкость предмета **не пропадает** при подборе/сохранении/смене карты.
- Базовые статы предметов **не меняются**, RTL просто накладывает аффиксы.
- Не ломает сейвы.
- Тултип и цвет рамки соответствуют тиру.
- Жёстких капов больше нет: несколько Legendary-вещей могут довести значение до естественного предела (drain до 0, шанс до 100%).
- Unbreakable держит прочность на значении, с которым предмет найден; ремонт это значение поднимает.
- Аффиксы получает только новый лут: у уже лежащих в сейве предметов их не будет.
