# Спецификация рефакторинга RoadToLoot

## Цель
Упростить кодовую базу: убрать дублирование, мёртвый код, лишние прокси-слои. Сохранить текущее поведение модa.

## Принципы
- Не менять функционал. Только рефакторинг.
- Минимальные правки, проверка после каждого шага сборкой через `pack.ps1`.
- Убрать только явно мёртвый/дублирующий код.

## Этапы

### Этап 1. Удалить RTLApply.gd
**Файл:** `mods/RoadToLoot/RTLApply.gd`  
**Причина:** Полностью проксирует `RTLStore`/`RTLSidecar`. Нигде по коду не используется напрямую (проверить перед удалением).

**Действия:**
- Найти все использования `RTLApply` в проекте
- Заменить вызовы на прямые вызовы `RTLStore`/`RTLSidecar`
- Удалить файл
- Убрать из `pack.ps1` (если есть явный список файлов) или просто не добавлять

### Этап 2. Упростить RTLSidecar
**Файл:** `mods/RoadToLoot/RTLSidecar.gd`

**Действия:**
- Удалить `prepare_slot()` и `commit_slot()` - пустые заглушки
- Оставить только используемый функционал: `get_uid`, `ensure_uid`, `get_plate`, `set_uid`, `set_plate`, `read`, `populate`, `clear_slot`

### Этап 3. Упростить RTLStore
**Файл:** `mods/RoadToLoot/RTLStore.gd`

**Действия:**
- `uid()` -> может остаться как удобный алиас или заменить вызовы на `RTLSidecar.get_uid()`. Предпочтительнее убрать прокси и вызывать напрямую.
- `plate()` -> убрать или оставить минимально
- `populate()` -> вызывать `RTLSidecar.populate()` напрямую
- `clear()` оставить (используется в `RTLApply.clear` и может использоваться)
- Проверить все вызовы

### Этап 4. Почистить RTLBoot
**Файл:** `mods/RoadToLoot/RTLBoot.gd` (912 строк)

**Действия:**
- Удалить неиспользуемую переменную `_container_connected`
- Убрать или сильно сократить дебажные логи `[RTL-DBG]` (оставить только критичные при необходимости)
- Упростить дублирующуюся логику ребайдинга между `_pending_add_container` и `on_lootcontainer_createslot` - вынести в хелпер `_find_existing_by_file_tier(file, t) -> String`
- Упростить `_apply_grid` и `_apply_all_under` - вынести общую логику восстановления по `by_uid/by_ft` в хелпер
- Убрать временные комментарии `# TEMP:` 
- Проверить `_sidecar_retry` - оставить если используется, иначе убрать

### Этап 5. Проверка и сборка
- Сборка через `pack.ps1`
- Проверка отсутствия ошибок парсинга
- Убедиться что функционал не сломан
